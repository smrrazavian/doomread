# GPL-3.0, shipped as four build flavours

The app is GPL-3.0 from day one and ships as four Android flavours from one codebase:

- `fdroid`: fully free, no self-update
- `play`: carries the Accessibility declaration and disclosure
- `bazaar`: Cafe Bazaar
- `apk`: direct download, with its own update check

The server may live in a separate repository under its own licence. Changing to a permissive licence later would need every contributor's agreement.
