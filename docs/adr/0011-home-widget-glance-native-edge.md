# The home screen widget is drawn with Glance, from strings the app pushes

The widget shows the current Work's Road, whether tonight's Window is lit, and Start. Its UI is Jetpack Glance in one Kotlin file (`HomeWidget.kt`), and everything on it is worked out in Dart (`LiveHomeWidget`) in the app's language and pushed over a hand-written method channel. Kotlin keeps the last push in one DataStore and draws it, so the widget survives the app being killed and the phone restarting. The app language can differ from the phone's, so the push also says whether to lay out right to left, and Kotlin sets text alignment and row order from that, not from the launcher. Start reuses the notification's launch intent: back into the open Session, or a new one with the current Work.

Glance is the first real dependency on the native side: `androidx.glance:glance-appwidget` and the Kotlin Compose compiler plugin. Glance is AndroidX and Apache-2.0, and its runtime classpath brings in AndroidX (Compose runtime, DataStore, WorkManager) and kotlinx-coroutines but no Google Play services or Firebase (checked with `gradlew :app:dependencies`), so it holds to ADR-0002 in every flavour. We chose it over hand-written RemoteViews XML because Glance is what ADR-0001 named and keeps the layout in Kotlin, and over the `home_widget` plugin (named in the design doc) for the same reason as ADR-0009: we need two calls and a launch intent, and the plugin would add a dependency for that.

The widget refreshes itself every 30 minutes only so tonight's Window goes dark when the evening turns over at 4 in the morning; every other change is pushed by the app.
