# Sharing goes through a small Kotlin edge with a plain ACTION_SEND, and the image stays in the cache

The Finish poster is drawn in Dart: a fixed 360×640 widget captured from its own `RepaintBoundary` at 1080×1920, so it's the same image on every phone. Sharing it is the native part. Dart sends the PNG bytes, a file name and the share sheet's title over a hand-written method channel (`doomread/share`) to one Kotlin file (`ShareSheet.kt`). The Kotlin side writes the image to `cacheDir/share/`, turns it into a `content://` URI with `androidx.core`'s `FileProvider` (authority `${applicationId}.share`, limited to that one folder by `res/xml/share_paths.xml`), and starts `Intent.createChooser` around a plain `ACTION_SEND` of `image/png`. On Linux there's no share sheet to hand it to, so the image is saved to the user's XDG Pictures folder (`XDG_PICTURES_DIR` from `user-dirs.dirs`, else `~/Pictures`), and the app says where it went.

Rules for the file, because a poster may carry the user's Note, and Notes are private by default:

- It's written only to the app's cache, never to shared storage, so no storage permission is needed and no other app can list it.
- The provider isn't exported. Read access goes only to the app the user picks in the chooser, through `FLAG_GRANT_READ_URI_PERMISSION` and the intent's `ClipData`, and lasts only while that app holds the intent.
- Only the newest poster is kept. Each share clears the folder first, and the folder is deleted the first time the app's Activity starts in a new process. It isn't deleted as soon as the chooser returns, because the receiving app may still be reading it then.

We chose this over `share_plus` for the same reasons as ADR-0009 and ADR-0011. We need one call, and the plugin would add a dependency and its own `FileProvider` for it. It also does more than we need (files, text, URIs, result callbacks across iOS, web and desktop), and we'd be relying on its choice of where files go and how long they stay, which is the part that matters for a private Note. The edge holds to ADR-0002 in every flavour. `ACTION_SEND` and the chooser are framework APIs, and `FileProvider` is in AndroidX `core` (Apache-2.0), which the app already gets through the Flutter embedding and Glance (ADR-0011) without Google Play services or Firebase. The cost is one Kotlin file, one line in `MainActivity`, a `<provider>` in the manifest and a paths file.
